# 每月数据更新口径

1. 使用当月最新评论工作簿重新生成 `data` 目录，不在网页中手工填写统计数。
2. 一级关注大类固定为：性能效果、质量材质、外观设计、安装适配、品牌信任、气味环保、服务售后、物流包装、价格价值。大类不随月份改名，保证趋势可比。
3. 品类细分焦点按产品语境识别，例如地漏的排水、防臭和芯体适配，涂料的色差、遮盖和附着。
4. 一条评论可同时命中多个大类；提及率 = 命中该大类的去重评论数 ÷ 当期该品类去重评论数。
5. 公开页面只发布汇总指标和分类结果，不发布评论原文、Excel原行号或原文下载。每月源工作簿单独保存在本地备查目录。
6. 当前长期更新基线为 `data/product-scope.json` 保存的60个商品ID不可逆哈希；如后续工作簿新增或移除ID，构建程序会先停止并提示确认，避免无意改变范围。
7. 每月生成后检查：商品ID数量与映射、品类数、日期上限、有效去重/原始评论量、关注覆盖率、各品类TOP3关注点，并扫描公开文件确认不含原评论。
